# diy-pearl

**拼豆模拟器 (Perler Beads Simulator)** —— 在电脑上模拟拼豆/烫珠像素手工的交互工具。

## 功能

- **可调画布** — 自由设置拼豆模板的宽高（如 10×10 ~ 50×50）
- **圆形豆子渲染** — 每个豆子绘制为带高光的圆珠，模拟真实拼豆质感
- **多种编辑工具**
  - 点击涂色 / 擦除
  - 拖拽连续画
  - 吸管取色
  - 撤销 / 重做
- **预设色板 + 可扩展** — 内置一组基础颜色，预留接口方便添加 Perler 标准色或自定义色彩
- **熨烫模拟** — 点击"熨烫"后相邻同色豆子边缘熔合，产生定型后的平整效果

## 技术栈

| 层 | 选型 |
| --- | --- |
| 渲染 | HTML5 Canvas |
| 语言 | 原生 JavaScript（ES Modules） |
| 构建 | 无（零依赖，浏览器直接打开） |
| 风格 | CSS（自定义属性主题） |

## 快速开始

```bash
git clone <repo-url>
cd diy-pearl
# 直接用浏览器打开 index.html
open index.html
```

## 项目结构

```
diy-pearl
├── index.html          # 入口页面
├── style.css           # 全局样式
├── src/
│   ├── main.js         # 应用入口，初始化
│   ├── canvas.js       # Canvas 渲染引擎（网格、豆子、熨烫效果）
│   ├── grid.js         # 网格数据模型
│   ├── tools.js        # 编辑工具（画笔、橡皮、吸管）
│   ├── palette.js      # 色板管理（预设 + 扩展）
│   ├── history.js      # 撤销/重做
│   └── iron.js         # 熨烫模拟算法
└── README.md
```
